# AACC
Aplicativo para generar SdA siguiendo el modelo SEM

## Acceso a los agentes de Microsoft 365 Copilot

Es obligatorio iniciar sesión con la cuenta oficial `@educastillalamancha.es`. El botón con el nombre del agente intenta copiar el contexto y abre su chat en una pestaña nueva; «Copiar contexto» copia la información sin abrir el chat. En Copilot, hay que pegar el texto con `Ctrl+V` y pulsar «Enviar»: el aplicativo no envía la consulta ni incorpora la respuesta automáticamente. Si la copia falla, se puede pulsar «Copiar contexto» y revisar los permisos del portapapeles. No se deben usar iniciadores de conversación (*conversation starters*).

El tutorial paso a paso está disponible en la portada del aplicativo, antes de iniciar el asistente.
